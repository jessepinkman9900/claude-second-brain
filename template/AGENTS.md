# AGENTS.md

This vault is a personal knowledge wiki maintained by an AI agent. The full schema and operating instructions live in [`CLAUDE.md`](./CLAUDE.md) — they apply to every agent, not just Claude.

**Before doing any wiki work, read `CLAUDE.md` and follow it exactly.** In particular:

- Never modify anything in `raw-sources/`.
- The wiki lives only in `wiki/`; always append to `wiki/log.md`, never overwrite it.
- Use the ingest, query and lint workflows defined there (also available as the `brain-ingest`, `brain-search`, `lint`, `brain-refresh` and `brain-rebuild` skills).
