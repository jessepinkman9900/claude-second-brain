# csb path

Print a path for the default (or named) brain.

## Usage

```bash
csb path [root|qmd|config] [--brain <name>]
```

The global skills (`/brain-ingest`, `/brain-search`, `/brain-refresh`) call this to resolve paths at run time, so they work from any working directory.

## Arguments

### kind

`'root' | 'qmd' | 'config'` (default: `'root'`)

| Value | Prints |
|---|---|
| `root` | The brain's directory, e.g. `~/.claude-second-brain/my-brain` |
| `qmd` | The brain's qmd SQLite index, e.g. `~/.claude-second-brain/my-brain/.qmd/index.sqlite` |
| `config` | The central `~/.claude-second-brain/config.toml`. Ignores `--brain`. |

```bash
csb path qmd
```

## Options

### --brain \<name\>

`string`

Target a specific brain instead of the default.

```bash
csb path qmd --brain work
```

### --root, --qmd, --config

`boolean` (deprecated)

Old flag form of the `kind` argument. Still works, and prints a warning to stderr.

### -h, --help

Displays help message.

```bash
csb path --help
```
