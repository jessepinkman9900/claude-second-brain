# csb doctor

Verify your setup and suggest fixes.

## Usage

```bash
csb doctor
```

## Checks

- Installed tools: `gh` (and its auth status), `mise` or `pnpm` 10+, and `wrangler` (optional).
- A parseable `~/.claude-second-brain/config.toml`.
- At least one registered brain, and a default brain that resolves.
- For each brain: the `path` directory and the `qmd_index` file exist.
- Each global skill is installed in `~/.agents/skills` at this release's version.

Each failed or warning check prints a `Fix:` hint with the exact command to run. Exits non-zero when a check fails.

## Options

### -h, --help

Displays help message.

```bash
csb doctor --help
```
