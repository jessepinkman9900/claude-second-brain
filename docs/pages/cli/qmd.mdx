# csb qmd

Run [qmd](https://github.com/tobi/qmd) against the default (or named) brain.

## Usage

```bash
csb qmd [--brain <name>] [--] <qmd args…>
```

Forwards every argument that isn't a `csb` flag to `npx @tobilu/qmd`, with `INDEX_PATH` set to the brain's qmd index and the working directory set to the brain's root.

## Arguments

### qmd args

`string[]`

Passed to qmd as is.

```bash
csb qmd query -c wiki "distributed systems"
```

## Options

### --brain \<name\>

`string`

Target a specific brain instead of the default.

```bash
csb qmd --brain work search -c wiki "kafka"
```

### --

Optional separator. Everything after it goes to qmd verbatim. Use it only to pass a literal `--brain` (or another `csb` flag) through to qmd.

```bash
csb qmd -- --brain literal-qmd-flag
```

### -h, --help

Displays help message.

```bash
csb qmd --help
```
