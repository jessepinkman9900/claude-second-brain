# csb skills

Install or update the wiki skills for any agent.

## Usage

```bash
csb skills [--agent <ids>] [--copy] [--brain <name>]
csb skills --list
```

The skills follow the [Agent Skills](https://agentskills.io/specification) format and are installed with the same layout as [`npx skills`](https://github.com/vercel-labs/skills). See [Install skills for any agent](#install-skills-for-any-agent) below.

## Options

### -a, --agent \<ids\>

`string` (default: `claude-code` plus detected agents)

Agents to install for, comma-separated, or `all`. Also read from `CSB_AGENTS`. Without either, the CLI prompts (interactive) or uses Claude Code plus every detected agent (non-interactive).

```bash
csb skills --agent codex,cursor
```

### --copy

`boolean`

Copy skills into each agent's folder instead of symlinking them to `~/.agents/skills`.

```bash
csb skills --agent all --copy
```

### --brain \<name\>

`string`

Brain whose vault-local skills to update. Defaults to the default brain.

```bash
csb skills --brain work
```

### --list

`boolean`

List the supported agents and where each reads skills.

```bash
csb skills --list
```

### -h, --help

Displays help message.

```bash
csb skills --help
```

## Install skills for any agent

- **Global skills** (`brain-ingest`, `brain-search`, `brain-refresh`) are written once to `~/.agents/skills/<name>`, with a `.csb-version` marker. Codex, Cursor, GitHub Copilot, Gemini CLI, OpenCode, Amp and Cline read `~/.agents/skills` directly.
- Agents with their own folder get a **symlink** to the shared copy: `~/.claude/skills` (Claude Code, honours `CLAUDE_CONFIG_DIR`), `~/.codeium/windsurf/skills`, `~/.config/goose/skills`, `~/.kiro/skills`, `~/.roo/skills`, `~/.continue/skills`, `~/.junie/skills`, `~/.augment/skills`. If a symlink can't be created, or with `--copy`, the skill is copied instead.
- **Vault-local skills** (`brain-rebuild`, `lint`) stay in the vault's `.claude/skills/` and are copied (never symlinked, since the vault is a git repo) into each other selected agent's project folder (`.agents/skills/`, `.windsurf/skills/`, …) of the default brain, or the one named with `--brain`. Commit them to sync.

Agents are detected by their config folder (e.g. `~/.codex`, `~/.cursor`, `~/.copilot`). Upgrading from a release that installed only to `~/.claude/skills`: run `csb skills` once, and existing copies there are replaced with symlinks to `~/.agents/skills`.
