# csb ls

List all registered brains.

## Usage

```bash
csb ls
```

Alias: `csb list`.

Prints each brain in `~/.claude-second-brain/config.toml` with its path, creation date and git remote. The default brain is shown in bold with a `*` marker.

## Options

### -h, --help

Displays help message.

```bash
csb ls --help
```
